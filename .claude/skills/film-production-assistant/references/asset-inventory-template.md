# Asset Inventory Template

Populate this with verified repository paths. The user's supplied assets are stored in `Film-References/Film Industry DR/`.

For every asset record: exact path, filename, asset type, what it depicts, approved-master/draft status, and continuity restrictions. Never invent filenames or mark a missing asset as available.

Suggested categories:
- Main characters: Ben, Rock, Anna, Avven
- Side characters
- Vehicle: Anna's dark navy-blue sedan
- Locations: city, bridge, school, forbidden forest
- Creature: The Pale Mimic
- Scene final frames and continuity handoffs

If multiple versions exist and no master is marked, ask the user which one is approved.
